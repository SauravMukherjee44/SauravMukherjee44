# Profile visual assets

- `hero.svg` is an original animated perspective projection of a five-node 3D network. The vertices rotate through 73 frames over 24 seconds; node size, shading, face geometry, and line opacity provide depth. Labels remain stationary for readability. `hero-static.svg` is its still fallback for reduced-motion preferences.
- `footer.svg` is original green dot-matrix lettering with a gentle shimmer, inspired by the visual language of GitHub's contribution grid. This is decorative artwork, not a chart or a claim about contribution activity. `footer-static.svg` is the reduced-motion fallback. The README selects still variants through `<picture>` sources.
- The six project cards and the social pills are original SVG layouts. Rebuild all original artwork with `node scripts/build-profile-assets.mjs` (Node.js, no dependencies). Geometry, colors, copy, and animation remain editable in `scripts/profile-branding.mjs` and the main generator.
- Brand paths in `social-icons.json` for GitHub, Instagram, X, YouTube, Telegram, Discord, and Gmail come from [Simple Icons](https://github.com/simple-icons/simple-icons), CC0-1.0. See `LICENSE.simple-icons`. The LinkedIn mark is reused from Saurav's portfolio; the portfolio compass is original. Marks belong to their respective owners and imply no endorsement.
- `typing.svg` was generated with [DenverCoder1/readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg) (MIT). It uses original profile copy, a local dark background, and a system monospace font; the generated embedded font was removed. Upstream license: `LICENSE.readme-typing-svg`.
- `stack.svg` was generated with [tandpfun/skill-icons](https://github.com/tandpfun/skill-icons) (MIT), using `py,ts,react,nextjs,fastapi,pytorch,azure,aws,docker,terraform,postgres,git`, dark theme, twelve icons per line. Upstream license: `LICENSE.skill-icons`.
- Layout references: [awesome-github-profile-readme](https://github.com/abhisheknaiidu/awesome-github-profile-readme). Green-grid animation references: [Platane/snk](https://github.com/Platane/snk) and [github-readme-activity-graph](https://github.com/ashutosh00710/github-readme-activity-graph). No source code or personal claims were copied from these inspiration references.
- `LICENSE.capsule-render` is retained for the previous generated footer in Git history. The current footer is original and does not use Capsule Render.

All SVG assets are stored locally, contain no scripts or foreignObject elements, and need no credentials, services, or scheduled workflows. Existing profile artwork and Git history are retained. The README supports animation and navigation links, not an interactive 3D canvas.

Project descriptions were checked against the public repositories. Career and community details were cross-checked with Saurav's portfolio and resume. CodeIN figures describe historical community milestones and its preserved contributor baseline, rather than live counters. SwaPilot is presented as a product direction with a pilot/demo repository; HealthAI is presented as educational research. Community links are omitted from the profile README at Saurav's request.
